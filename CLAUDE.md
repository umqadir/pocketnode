# pocketnode

Read `HANDOFF.md` in full before doing anything. It has the agreed design, the user's principles and the build order. Then read `RESEARCH-NOTES.md`, which holds the sourced findings; more get appended as research finishes.

Key rules from the user:
- Only real platform limits restrict scope. Don't add your own.
- Be idiomatic and correct by default. The user shouldn't have to remember restrictions.
- Research before making design decisions.
- Blue-sky items (HANDOFF §8) stay parked unless they prove straightforward or clearly worth it.
- Run the on-device experiments in HANDOFF §9 step 2 early. Several design branches depend on them.
